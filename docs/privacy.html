XXOSXX.exe — Privacy Policy

Last updated 11 November 2026

1. Who runs the bot

XXOSXX.exe is a private Discord bot for one server, xX☆Online☆Status☆Xx. It is run by the server owner, BabyyBATxoxo (“the owner”), who decides how it is used and is the contact for anything in this policy.

2. What the bot stores

  • Moderation records. Your Discord user ID, the type of action (warning, timeout, kick, ban), the reason, notes, and links or message IDs used as evidence.
  • Automatic moderation incidents. Your user ID, the channel and message ID, which rule was triggered (for example “7 messages in 5 seconds” or a blocked link’s domain) and what the bot did.
  • Audit log. A record of bot actions: who did something (user ID), what it was, the target and the result. This includes refused attempts to use owner-only commands. Role-panel clicks are only counted per role, not recorded per member.
  • Verification. Your user ID, verification status, number of attempts and, if refused, the reason.
  • Server statistics. Message counts per channel per day and the daily member count. These are totals only and are not linked to any member.
  • Server configuration. Settings, role panels, automatic replies, scheduled messages and backups of that configuration. Backups are encrypted.

3. Message content

The bot reads messages as they are sent so it can apply the server’s moderation rules and answer trigger words. It does not keep a copy of your message text. Moderation records hold links and message IDs, not copied messages.

4. What the bot does not do

  • It does not sell data or share it with advertisers or any third party.
  • It does not read direct messages between members.
  • It does not collect email addresses, IP addresses, payment details or passwords from members.
  • It does not use your data to train AI models.

5. Why the data is kept

To keep the server safe, to let the owner review moderation decisions, to run features members use (verification, role panels), and to show the owner how the server is doing.

6. Where it is kept and who can see it

Data is stored in a database on a computer the owner controls. Only the owner can view it, through owner-only bot commands and a control panel that requires the owner’s Discord sign-in. The bot works through Discord, so Discord’s own privacy policy also applies to what you do there.

7. How long it is kept

  • Audit log: 180 days by default (the owner can change this), then deleted automatically.
  • Finished verification records, alerts and scheduled-message run history: 90 days.
  • Server statistics: 2 years.
  • Moderation cases, warnings and automatic moderation incidents: kept until the owner deletes them, so repeat behaviour can be recognised.

8. Your choices

You can ask the owner to show you what the bot holds about you, to correct it, or to delete it. Message BabyyBATxoxo on Discord in the xX☆Online☆Status☆Xx server. Some moderation records may be kept where they are needed to protect the server. Depending on where you live, you may have further rights under local data-protection law.

9. Children

Discord requires users to be at least 13, or older where local law says so. The bot is not meant for anyone below that age.

10. Changes

This policy may be updated; the date at the top shows the latest version.
